# Asset provenance

`icon.svg` is generated from the SVG source embedded in
`scripts/generate-icon.js`; `icon.png` is a raster rendering of that same local
source. The design uses basic geometric shapes and contains no downloaded
photograph, font file, commercial icon pack, or third-party artwork.

The downward-arrow convention is commonly associated with Markdown. The
published Markdown mark by Dustin Curtis is separately dedicated under CC0,
but this project's icon is not copied from that asset.
