# Security Policy

## Supported versions

The latest published release receives security fixes. Older releases should be
upgraded before a report is reproduced.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's
private vulnerability reporting feature for this repository when available:

https://github.com/Yang200307/desk-notes/security/advisories/new

Include the affected version, reproduction conditions, expected impact, and a
minimal proof of concept. Do not include private documents, credentials, or
unredacted local paths. Receipt should be acknowledged within seven days.
